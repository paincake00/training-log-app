# Тренировки

Персональное Android-приложение для ведения дневника тренировок.

- Только локальные данные, без сети и аккаунтов.
- Русский интерфейс.
- Два экрана: бесконечный лог тренировок и недельный план.
- Прогрессия упражнений — свободный текст в привычной форме: `5/20-5/20-5/0`, `60-60-60`, `45/45-45/45`.

## Статус

Каркас приложения, слой данных и недельный план готовы: Room-схема, репозиторий, транзакции, тесты и экран плана с пресетами. Сейчас в разработке экраны лога и тренировки.
