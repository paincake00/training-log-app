# Тренировки

Персональное Android-приложение для ведения дневника тренировок.

- Только локальные данные, без сети и аккаунтов.
- Русский интерфейс.
- Два экрана: бесконечный лог тренировок и недельный план.
- Прогрессия упражнений — свободный текст в привычной форме: `5/20-5/20-5/0`, `60-60-60`, `45/45-45/45`.

## Статус

MVP готов: лог тренировок, недельный план и экран тренировки. Реализованы Room-схема, репозиторий, транзакции, автосохранение, пресеты, ручная синхронизация прогрессии в план и полный цикл тренировки.

## Релиз 1.0.0

- `versionCode = 1`, `versionName = "1.0.0"`.
- Подписанные артефакты: `dist/v1.0.0/training-log-1.0.0.apk` и `dist/v1.0.0/training-log-1.0.0.aab`.
- Контрольные суммы: `dist/v1.0.0/SHA256SUMS`.
- Установка APK: `adb install -r dist/v1.0.0/training-log-1.0.0.apk`.

Сборка release требует переменных окружения `TRAINING_LOG_STORE_FILE`, `TRAINING_LOG_STORE_PASSWORD`, `TRAINING_LOG_KEY_ALIAS`, `TRAINING_LOG_KEY_PASSWORD`. Keystore и пароли в репозиторий не попадают.
