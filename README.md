# Тренировки

Персональное Android-приложение для ведения дневника тренировок.

- Только локальные данные, без сети и аккаунтов.
- Русский интерфейс.
- Два экрана: бесконечный лог тренировок и недельный план.
- Прогрессия упражнений — свободный текст в привычной форме: `5/20-5/20-5/0`, `60-60-60`, `45/45-45/45`.

## Документация

- [PLAN.md](PLAN.md) — продуктовые требования, модель данных, экраны, тесты, acceptance criteria.
- [DESIGN.md](DESIGN.md) — UI-стандарт: сетка, цвета, типографика, компоненты, состояния.
- [AGENTS.md](AGENTS.md) — правила работы агентов: декомпозиция, суб-агенты, тесты, Definition of Done.

## Статус

MVP готов: лог тренировок, недельный план и экран тренировки. Реализованы Room-схема, репозиторий, транзакции, автосохранение, пресеты, ручная синхронизация прогрессии в план и полный цикл тренировки. Остались полировка, ручные проверки и будущие улучшения из `PLAN.md`.
